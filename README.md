
# Snake Game 🐍

A modern, responsive Snake game built with HTML5 Canvas, CSS3, and vanilla JavaScript.

## Features

- **Classic Snake Gameplay**: Control the snake to eat food and grow longer
- **Modern UI**: Beautiful gradient design with glassmorphism effects
- **Responsive Design**: Works on desktop and mobile devices
- **Score Tracking**: Keep track of your current score and high score
- **Local Storage**: High scores are saved locally
- **Keyboard Controls**: Use arrow keys or WASD to control the snake
- **Game Controls**: Start, pause, and reset functionality

## How to Play

1. Open `index.html` in your web browser
2. Click "Start Game" to begin
3. Use arrow keys or WASD to control the snake
4. Eat the red food to grow and increase your score
5. Avoid hitting the walls or yourself
6. Try to beat your high score!

## Controls

- **Arrow Keys** or **WASD**: Move the snake
- **Start Game**: Begin a new game
- **Pause/Resume**: Pause or resume the current game
- **Reset**: Start over with a new game

## Technical Details

- Built with vanilla JavaScript (ES6+)
- Uses HTML5 Canvas for smooth graphics
- CSS3 with modern features like backdrop-filter and gradients
- Responsive design with mobile-first approach
- Local storage for persistent high scores

## Files

- `index.html` - Main HTML structure
- `style.css` - CSS styling and responsive design
- `script.js` - Game logic and JavaScript functionality
