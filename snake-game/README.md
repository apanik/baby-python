# 🐍 Snake Game

A modern, responsive Snake game built with HTML5 Canvas, CSS3, and vanilla JavaScript.

## Features

- **Classic Snake Gameplay**: Control a snake to eat food and grow longer
- **Score System**: Track your current score and high score (persisted in localStorage)
- **Responsive Design**: Works on desktop and mobile devices
- **Modern UI**: Beautiful gradient design with smooth animations
- **Game Controls**: 
  - Arrow keys or WASD to control the snake
  - Start/Pause/Resume functionality
  - Restart game option
- **Game Over Screen**: Shows final score and option to play again

## How to Play

1. Click "Start Game" to begin
2. Use arrow keys or WASD to control the snake
3. Eat the red food to grow and increase your score
4. Avoid hitting the walls or the snake's own body
5. Try to achieve the highest score possible!

## Installation

Simply open `index.html` in your web browser. No additional setup required!

## Game Controls

- **Arrow Keys** or **WASD**: Move the snake
- **Start Game**: Begin a new game
- **Pause/Resume**: Pause or resume the current game
- **Play Again**: Restart after game over

## Technical Details

- Built with vanilla JavaScript (ES6+)
- Uses HTML5 Canvas for game rendering
- CSS3 for modern styling and animations
- localStorage for high score persistence
- Responsive design with mobile support

## Browser Compatibility

Works in all modern browsers that support:
- HTML5 Canvas
- ES6 JavaScript features
- CSS3 gradients and animations
